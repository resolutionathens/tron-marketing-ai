# /seo-report — work with the Search Console report

The GSC report is **already produced** by `tron-search-console` (the "Facilitron GSC Analyzer"). This
skill does NOT re-pull or re-derive Search Console data — it helps you **get** that report and then
**work with it**: summarize it, translate it for leadership, turn it into slides, and file the
follow-ups. Git-free.

## Where the report comes from

The analyzer runs one pipeline two ways, both emitting the **same markdown report** (executive
summary, CTR-improvement opportunities, organic CTR-by-position benchmarks, trending queries,
rental-intent analysis, category breakdowns, high-impression queries):

- **Hosted app — what most people use:** **https://seo.facilitron.work** (behind Cloudflare Access;
  sign in with an allowlisted `@facilitron.com` Google account). Pick a period, generate, read it with
  the in-app guide at `/guide`. No setup. **Point non-technical SEO users here.**
- **CLI — for engineers:** the global **`/tron-report`** skill, or in a `tron-search-console` checkout
  `uv run python quick_report_simple.py` / `uv run gsc-report`. Default property
  `sc-domain:facilitron.com`; periods `2w` / `1m` / `3m` / `6m`.

## 1. Get the report
Ask which the user has. If they don't have one yet: non-technical → send them to seo.facilitron.work;
engineer → run `/tron-report`. Then load the markdown (a pasted block, or a saved path) — that's the
input for everything below.

## 2. Work with it
- **Leadership summary** — condense to headline + the few things that matter, framed per the analyzer's
  c-suite guide (`/guide` / `docs/csuite-report-guide.md`). Always keep the **period comparison** the
  report carries; a summary without the delta is noise. Prose, no em dashes.
- **Deliverables** — `tron:md-to-pdf` for a branded PDF; for the monthly **report-to-carousel** (MCR-353),
  pull the headline tiles + top movers into slide-ready bullets.
- **Follow-ups** — route the report's own findings into action:
  - CTR-improvement opportunities + page-2 trending queries → `tron:landing-page-seo` / `tron:keyword-research`.
  - File the work as Jira tasks via the manager's `tron:board-scaffold`, or note status with `tron:jira-comment`.

## 3. Optional GA4 context
For traffic/conversion context the GSC report doesn't cover, use the **analytics MCP** (`run_report`,
`run_realtime_report`) — sessions, engaged sessions, conversions, and landing-page/district
segmentation (cf. MCR-335 district-level tracking). Keep this supplementary; GSC is the report's core.

## Rules
- Don't reproduce what the analyzer already computes — get its output, don't rebuild it.
- Don't fabricate numbers. Quote the report; if a section is missing, say so.
- Preserve the period-over-period comparison in anything you hand off.

## Output
A shareable summary (markdown, default `/tmp/seo/seo-report-<period>.md`) plus whichever deliverable was
asked for, and a short list of the follow-up tasks the data warrants.
