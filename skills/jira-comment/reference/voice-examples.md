# Comment Voice Examples

## Example

> Updated the product hero so the background image can either tile as a repeating pattern (the current behavior) or fill the whole section as a cover image, both over a chosen background color. The tile size is now adjustable too, giving more ways to vary heroes between sections. All existing heroes are unaffected since the new options are opt-in. Live on dev now for review, PR #709.

The example is prose, has no bullets or em dashes, avoids code identifiers, and ends with a useful status pointer.

## Anti-patterns

- Do not echo a conventional commit message. Rewrite the outcome in plain language.
- Do not list every change as bullets. Combine related updates into one sentence.
- Do not use em dashes.
- Do not restate the ticket title. Explain what changed since the ticket was filed.
- Do not write a multi-paragraph essay. Put detailed technical context in the PR or a document.
